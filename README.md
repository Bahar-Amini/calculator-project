# Calculator

A simple terminal-based calculator project built with Python.

This project was created mainly to practice Object-Oriented Programming (OOP) and Git/GitHub through building a complete project from scratch.

## Features

- Basic arithmetic operations
- Input validation
- Error handling
- Calculation history
- Handling invalid inputs
- Handling division by zero
- Floating-point number support
- Unit tests with Pytest

## Technologies

- Python
- Object-Oriented Programming (OOP)
- Git & GitHub
- Pytest
- Ruff
